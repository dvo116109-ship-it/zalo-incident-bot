Zalo Incident Bot

Zalo Incident Bot is a private incident management and reporting automation application.

Application Purpose

The application helps authorized operators collect incident reports, organize incident photographs, and synchronize incident records.

Main Features

  • Collect incident reports from Zalo.
  • Store incident records in a database.
  • Upload incident photographs to Google Drive.
  • Synchronize incident records with Google Sheets.
  • Send incident status reminders.

Google API Usage

Google Drive and Google Sheets APIs are used to support authorized incident management and reporting operations.

This application is intended for private use and is not offered as a public service.
